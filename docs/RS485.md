# RS-485 Interface

The board uses an SP3485 half-duplex transceiver. A fixed 120 Ω termination resistor and fixed bias resistors are present in the production schematic; there is no termination-selection jumper. The current SDK does not implement an RS-485 API; see [SDK API Reference](./sdk_api_reference.md).

![Production board RS-232 and RS-485 schematic](./schematics/SCH_Schematic3_3-RS232-RS485-interface_2026-10-26.png)

## Electrical standard

RS-485 carries balanced differential data. This board uses half-duplex direction control and includes a fixed 120 Ω termination and fixed bias network. Termination is not jumper-selectable; account for it when placing the board on a shared bus. A/B polarity labels can vary between vendors, so verify the peer device documentation.

## Bus connector

| Pin | Signal |
|---:|---|
| 1 | RS485-B |
| 2 | RS485-A |
| 3 | `GND` |

Confirm connector orientation and A/B polarity against the connected equipment.

## MCU routing

| Signal | ESP32 GPIO / UART2 net | Function |
|---|---|---|
| Transmit data | UART2 TX, `UART-RS485-TX2` | Transceiver data input |
| Receive data | UART2 RX, `UART-RS485-RX2` | Transceiver data output |
| Direction | GPIO 15, `RS485-TX-EN` | HIGH transmits; LOW receives |

The direction-control net has a pull-down in the schematic. UART2 TX/RX routing is selected through the [2×15 jumper field](./jumper_configuration.md#2x15-through-hole-jumper-field). Firmware must switch direction and wait for the UART’s final stop bit to leave before returning to receive mode.
